# Лабораторная работа №1. Динамический парсинг

Дисциплина: «Программные средства сбора, консолидации и аналитики данных». Вариант 27.

Данные собраны с учебного стенда через Playwright и разобраны с помощью XPath. Реализованы закрытие cookie-баннера, ожидание загрузки, догрузка всех 30 строк, очистка чисел и построение четырёх графиков.

В `ЛР1_вариант27.ipynb` находятся код, результаты и выводы. В `lr1_variant27.xlsx` сохранены данные и сводка по секторам, в `page.png` показана собранная страница. Стенд встроен в ноутбук, поэтому отдельный HTML для запуска не нужен.

Данные учебные. Реальные котировки Yahoo Finance в работе не собирались.
